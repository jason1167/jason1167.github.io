# 新進人員使用說明書測驗網站

一個活潑可愛的互動式測驗網站，協助新進員工快速建立個人工作使用說明書。

## 快速開始

### 啟動網站

```bash
# 啟動本地伺服器
npx -y http-server . -p 8080
```

然後在瀏覽器中開啟：http://127.0.0.1:8080

### 檔案結構

```
NewEmployee/
├── index.html    # 主頁面
├── style.css     # 樣式設計
├── app.js        # Vue.js 應用程式
└── README.md     # 說明文件
```

## 功能特色

- ✨ 8 題快速測驗，涵蓋工作節奏、方式、偏好、承諾和地雷
- 🎨 活潑可愛的視覺設計，柔和漸層色與流暢動畫
- 📊 自動產生個人化工作使用說明書
- 💾 支援下載報告（.txt 格式）
- 📱 完整響應式設計，支援手機、平板、桌面

## 技術資訊

- **框架**：Vue.js 3（CDN 版本）
- **語言**：JavaScript（無 TypeScript）
- **樣式**：原生 CSS
- **類型**：單頁式靜態網站

## 部署建議

此為純靜態網站，可直接部署到：
- GitHub Pages
- Netlify  
- Vercel
- 任何靜態網站託管服務

只需將所有檔案上傳即可，無需伺服器端處理。

## 瀏覽器支援

支援所有現代瀏覽器：
- Chrome 90+
- Firefox 88+
- Safari 14+
- Edge 90+
