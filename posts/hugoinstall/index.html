什麼是 Hugo#

  • 一套網站製作的系統，只需使用 Markdown 語法，即可製作網站/網頁，且有豐富的工具與Theme，讓網頁製作更完整。

  • 最大特點是所有的網頁內容都由你來掌握，不會被平台所綁架。

Windows 環境安裝#

安裝 GoLang (Hugo 是跑在 GoLang)#

1
2

# 使用 winget 工具安裝
winget install GoLang.Go

1
2
3
4
5

# 利用 winget 安裝

hugo version
