專案結構
myblog/
├─ archetypes/ 新內容的模板
├─ assets/     靜態檔案 (如：圖片、js、css)
├─ content/    內容
│  └─ posts/   文章存放處
├─ data/       資料檔 (如：JSON, YAML, TOML)
├─ i18n/       多語言網站的翻譯表
├─ layouts/    將內容、資料和資源轉換為完整網站的範本
├─ public/     已發佈的網站
├─ resources/  Hugo資源resources管道的快取輸出 (包含 CSS 和圖片)
├─ static/     包含網站建置時將被複製到public目標目錄的檔案 (如 favicon.ico、圖片)
├─ themes/     網站樣式主題
│  └─ LoveIt/
└─ hugo.toml   site configuration

加入 Hugo theme（使用 git submodule 方式）#

Hugo 主題網站：https://themes.gohugo.io/

1
2
3
4
5

git init
git submodule add --depth=1 https://github.com/adityatelange/hugo-PaperMod.git themes/PaperMod

# 更新 theme
git submodule update --init --recursive

參考：三種 theme 安裝方式

  1. 使用 Git submodules 建置 —> 推薦

    • 能追蹤 theme 的升級，也算是能自己改動

  2. 手動 copy theme 檔案

    • 未來得自己手動升級

  3. 當作 Hugo Module (當成 Go Module) 安裝

    • 升級 theme 較容易，但無法更動內部程式

修改 Hugo.toml，指定 theme#

1
2

# 增加這行，指定 theme
theme = 'PaperMod'

執行網站#

1
2
3
4
5

# 編譯時，連同草稿文件一起顯示 (文章檔案最上方參數 draft=true)
hugo server -D

# 編譯時，不含草稿 (文章檔案最上方參數 draft=false)
hugo server

  • 執行指令後，會啟動 http://localhost:1313/，可用 Browser 看網站

  • 此時若修改 ./posts 目錄的文章，網頁會立即改變 (即時預覽)

編譯網站#

1
2
3
4
5

# 編譯網站，並輸出至 .\public 目錄
hugo

# 編譯網站，並指定 baseurl
hugo server -b https://jason1167.github.io

踩雷區#

  • 問題：編譯輸出後 (public 目錄)，html 檔內的網址路徑都是 http://localhost，造成上線後異常 (找不到檔案)。

    • 解決：只要編譯時，加入指定 baseurl 即可 hugo server -b ``<https://jason1167.github.io>
